## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-ping`
- `allow-bare-invalidate`
- `allow-bare-init`
- `allow-bare-start-file`
- `allow-bare-start-utf8`
- `allow-bare-start-bytes`
- `allow-bare-read`
- `allow-bare-write`
- `allow-bare-update`
- `allow-bare-suspend`
- `allow-bare-resume`
- `allow-bare-wakeup`
- `allow-bare-terminate`
